# Corte Fine Shine

Build a booking app for a hair salon called "Corte Fino". Clients sign up with email and password, pick a service, a date and an available time slot, and see a list of their upcoming bookings. Use a clean, modern design with a dark header and Spanish and English labels.

This project was built with [Lovable](https://lovable.dev).
